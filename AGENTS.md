# Pixi'VN JSDoc

This repository contains the API documentation site for Pixi'VN libraries. Module documentation is maintained in the `content/` Git submodules and wired into the Fumadocs app and its LLM endpoints.

## Build and run commands

Do not start the wiki, run its development or preview server, or run a build/export command unless the user explicitly requests it. This includes commands such as `npm run dev`, `npm run build`, and `npm run export`.
